# 任务拆解（G2）

32 个 Issue，按四个里程碑串起来。依赖用 `#编号` 表示，编号即 Issue 序号。

## 怎么用

1. 本地文件是**唯一草稿源**，改完再同步到 GitHub
2. 装好 `gh` 后执行 `scripts/create-issues.ps1`，一次性建到 GitHub（标签、里程碑一起带上）
3. 开始在 GitHub 上按 Issue 开工：一个分支、一个 PR、一个 Issue
4. PR 描述里写 `Closes #12`，合并后自动关闭
