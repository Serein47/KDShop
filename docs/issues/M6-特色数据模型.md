# M6 特色数据模型

目标：让数据库支持限量、定制、礼物这些真实商品属性，而不是所有商品都长一个样。依据 [ADR-0009](../adr/0009-数据模型特色化.md)。

前置：V3/V4 迁移已合并（表结构就位），#8 商品浏览开工时一并纳入。

---

## ISSUE-42 多维标签与筛选

- 里程碑：M6 特色数据模型
- 标签：`backend`, `frontend`, `catalog`
- 依赖：#8
- 需求：ADR-0009

**背景**：品类树之外，按工艺、材质、场景三个维度交叉筛选。

**验收线**
- [ ] 标签按维度分组返回；同一商品可挂多个维度多个标签
- [ ] 列表接口支持 `craft=`、`material=`、`occasion=` 组合筛选，与品类、关键词、价格区间可叠加
- [ ] 多维组合先取标签交集再分页，命中数与实际一致
- [ ] 前台筛选器按维度折叠展示，选中项写进 URL

**涉及**：`tags`/`product_tags`、`GET /products`、筛选组件

## ISSUE-43 作品档案与瑕疵确认

- 里程碑：M6 特色数据模型
- 标签：`backend`, `frontend`, `catalog`
- 依赖：#8
- 需求：ADR-0009

**背景**：限量、孤品、创作故事、手工痕迹说明。

**验收线**
- [ ] 商品详情返回 `editionSize`/`editionNo`/`isUnique`/`story`/`flawNote`
- [ ] 限量商品显示"限量 N 件 · 第 M 件"，孤品显示"仅此一件"
- [ ] `requiresFlawAck = true` 时，下单必须提交 `flawAck = true`，否则返回 `10001`
- [ ] 订单行快照记录当时勾选状态，售后时可查

**涉及**：`products` 档案字段、`orders` 或 `order_items` 确认标记、详情页

## ISSUE-44 定制项与订单快照

- 里程碑：M6 特色数据模型
- 标签：`backend`, `frontend`, `catalog`, `order`
- 依赖：#33, #34
- 需求：ADR-0009、ADR-0008

**背景**：刻字、尺寸、颜色等定制项，选中后进入订单快照并参与金额。

**验收线**
- [ ] 商家可定义定制项（文本/单选、必填、字数上限、加价）
- [ ] 详情页按定义渲染表单，必填未填时不能加购
- [ ] 下单写 `order_item_options` 快照，加价计入订单行小计与主单金额
- [ ] 定制项在商家子单、售后单、质检记录中可见

**涉及**：`product_options`、`order_item_options`、`POST /orders`

## ISSUE-45 礼物场景

- 里程碑：M6 特色数据模型
- 标签：`backend`, `frontend`, `order`
- 依赖：#11
- 需求：ADR-0009

**背景**：手作市集大量订单是送礼。

**验收线**
- [ ] 结算页可勾选礼物包装与贺卡，贺卡 ≤100 字
- [ ] 订单详情与商家子单显示礼物信息
- [ ] 发货邮件的模板包含礼物提示，包裹单打印贺卡内容
- [ ] 礼物选项不影响金额与库存

**涉及**：`orders` 礼物字段、结算页、发货邮件模板
