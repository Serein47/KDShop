# 页面清单与路由（G0）

## 顾客端（`/`）

| 路由 | 页面 | 核心内容 | 鉴权 |
|---|---|---|---|
| `/` | 首页 | 轮播、分类入口、热销 Top8 | 无 |
| `/category/:id` | 分类列表 | 筛选（价格区间/分类）、排序、分页 | 无 |
| `/search?q=` | 搜索结果 | 同列表 + 关键词回显 | 无 |
| `/product/:id` | 商品详情 | 图集、价格、规格选择、库存、加购 | 无 |
| `/cart` | 购物车 | 勾选、改数量、删除、合计 | 游客可用（本地） |
| `/checkout` | 结算 | 地址选择、优惠券、金额明细、提交 | 需登录 |
| `/pay/:paymentNo` | 支付页 | 跳转模拟网关、倒计时 | 需登录 |
| `/mock-pay/:paymentNo` | 模拟网关 | 成功/失败按钮、签名回调演示 | 无（模拟第三方） |
| `/orders` | 订单列表 | 状态 Tab、分页 | 需登录 |
| `/orders/:orderNo` | 订单详情 | 商品快照、金额、状态时间线、操作按钮 | 需登录 |
| `/account/profile` | 个人资料 | 昵称、手机、改密码 | 需登录 |
| `/account/addresses` | 地址簿 | 增删改、设默认 | 需登录 |
| `/account/coupons` | 我的优惠券 | 可用/已用/过期 | 需登录 |
| `/account/favorites` | 收藏夹 | 列表、取消收藏 | 需登录 |
| `/login` `/register` `/forgot` `/reset` | 认证页 | 表单校验、错误提示 | 无 |

## 运营端（`/admin`）

| 路由 | 页面 | 核心内容 | 最低角色 |
|---|---|---|---|
| `/admin/login` | 后台登录 | 独立入口 | — |
| `/admin/dashboard` | 看板 | 今日/近一周销售额、订单量、热销 Top5 | 客服（只读） |
| `/admin/products` | 商品列表 | 搜索、上下架、编辑、删除 | 运营 |
| `/admin/products/edit/:id?` | 商品编辑 | 基本信息、SKU 与库存、图片上传 | 运营 |
| `/admin/categories` | 分类管理 | 两级树、排序 | 运营 |
| `/admin/orders` | 订单列表 | 多条件检索、状态筛选 | 客服 |
| `/admin/orders/:orderNo` | 订单详情 | 发货、备注、状态时间线 | 客服（发货需运营） |
| `/admin/refunds` | 退款审核 | 同意/驳回、原因 | 客服 |
| `/admin/customers` | 顾客列表 | 搜索、订单数、禁用 | 客服只读 / 运营可改 |
| `/admin/coupons` | 优惠券 | 新建、发放、停用 | 运营 |
| `/admin/reviews` | 评价管理 | 隐藏/恢复 | 运营 |
| `/admin/roles` | 角色权限 | 用户角色分配 | 管理员 |
| `/admin/audit` | 审计日志 | 按操作人/时间/对象筛选 | 管理员 |

## 约定

- 路由懒加载；`/admin/*` 与顾客端共用一套构建，按前缀分包
- 未登录访问受保护路由 → 跳 `/login?redirect=`，登录后回跳
- 403 页面区分「未登录」与「无权限」，避免用户困惑
- 所有列表页支持 URL 携带筛选条件，刷新不丢状态
