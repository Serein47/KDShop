# 01 公共与认证

所有调用方共用。认证走会话 Cookie，非 GET 请求必须带 CSRF token。

---

## GET /auth/csrf

取 CSRF token，前端启动时调用一次。

**权限**：公开

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "token": "8f14e45fceea167a5a36dedd4bea2543", "headerName": "X-XSRF-TOKEN" } }
```

前端把 `token` 放进请求头 `X-XSRF-TOKEN`；token 随会话轮换，401 后重新获取。

---

## POST /auth/register

**权限**：公开

**请求**

```json
{ "email": "zhang@example.com", "password": "S3cure!pass", "nickname": "张三" }
```

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| email | string | 是 | 邮箱格式，全局唯一，最长 128 |
| password | string | 是 | 8–64 位，至少含字母与数字 |
| nickname | string | 是 | 2–20 字符 |

**响应 201**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "userId": 1001, "email": "zhang@example.com", "verifyEmailSent": true } }
```

**错误**：`10001` 参数不合法 · `40015` 邮箱已注册

> 注册成功不直接登录，需先验证邮箱。验证邮件写入 outbox，本地在 Mailpit 查看。

## POST /auth/login

**权限**：公开

**请求**

```json
{ "email": "zhang@example.com", "password": "S3cure!pass" }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": {
    "user": { "id": 1001, "nickname": "张三", "email": "zhang@example.com",
              "emailVerified": true, "roles": ["CUSTOMER"] },
    "merchant": null } }
```

商家登录时 `merchant` 返回：

```json
{ "merchant": { "id": 3, "shopName": "山野杂货", "status": "ACTIVE" } }
```

**错误**：`20003` 账号或密码错误 · `20004` 连续 5 次失败锁定 15 分钟 · `20005` 邮箱未验证 · `20006` 账号已禁用

**安全约定**：登录失败一律返回 `20003`，不区分「账号不存在」与「密码错误」，防用户枚举。

---

## POST /auth/logout

**权限**：登录

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3", "data": null }
```

会话立即失效，旧 Cookie 再请求返回 `20001`。

## POST /auth/verify-email

**权限**：公开

**请求**

```json
{ "token": "eyJhbGciOi..." }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3", "data": { "verified": true } }
```

**错误**：`20007` 链接无效或已使用

---

## POST /auth/resend-verification

**权限**：公开 · **限流**：同邮箱 60 秒一次

**请求**

```json
{ "email": "zhang@example.com" }
```

**响应 200**：恒返回成功，避免暴露邮箱是否注册

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3", "data": { "sent": true } }
```

---

**权限**：公开 · **限流**：同邮箱 60 秒一次

**请求**

```json
{ "email": "zhang@example.com" }
```

**响应 200**：恒返回成功（防枚举）

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3", "data": { "sent": true } }
```

---

## POST /auth/reset-password

**权限**：公开 · 令牌一次性，30 分钟过期

**请求**

```json
{ "token": "eyJhbGciOi...", "newPassword": "N3w!passw0rd" }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3", "data": { "reset": true } }
```

**错误**：`20007` 令牌无效或已使用 · `10001` 密码不合规

重置成功后该用户全部会话失效。

---

## PUT /auth/password

**权限**：登录

**请求**

```json
{ "oldPassword": "S3cure!pass", "newPassword": "N3w!passw0rd" }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3", "data": { "changed": true } }
```

**错误**：`20003` 旧密码错误

## GET /health

**权限**：公开 · 不做鉴权，供探活与发布冒烟使用

**响应 200**

```json
{ "status": "UP",
  "components": { "db": "UP", "redis": "UP", "storage": "UP" },
  "version": "0.1.0", "time": "2026-10-27T14:05:00+08:00" }
```

任一依赖 `DOWN` 时返回 HTTP 503。

---

## GET /meta

**权限**：公开 · 前端启动时读取

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": {
    "currency": "CNY",
    "timezone": "Asia/Shanghai",
    "shipping": { "freeThresholdCent": 9900, "feeCent": 1000, "perMerchant": true },
    "order": { "payTimeoutMinutes": 15, "autoConfirmDays": 15 },
    "settlement": { "protectionDays": 7 },
    "features": { "coupon": true, "review": true, "favorite": true, "agent": false } } }
```

> `features.agent = false` 是 V2 智能购物伙伴的开关，首版固定关闭。
