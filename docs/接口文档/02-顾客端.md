# 三、结算与下单

## POST /checkout/preview

结算前预览：算钱、拆单、算券，**不落库、不锁库存**。

**权限**：登录

**请求**

```json
{ "addressId": 12, "couponId": 5,
  "items": [ { "skuId": 101, "quantity": 2 }, { "skuId": 301, "quantity": 1 } ] }
```

| 字段 | 必填 | 说明 |
|---|---|---|
| addressId | 否 | 不传则用默认地址；影响运费（首版运费与地址无关，保留字段） |
| couponId | 否 | 传了但不可用时返回 40011 |
| items | 是 | 传 `cartItemIds` 或 `skuId+quantity` 二选一 |

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": {
    "subOrders": [
      { "merchantId": 3, "shopName": "山野杂货",
        "items": [ { "skuId": 101, "name": "手冲咖啡套装", "spec": { "颜色": "白色" },
                     "price": 12800, "quantity": 2, "subtotal": 25600, "requiresFlawAck": false, "flawNote": null,
                     "options": [ { "optionId": 9, "name": "刻字内容", "value": "小明", "priceDelta": 1000 } ] } ],
        "goodsAmount": 25600, "shippingFee": 0, "discount": 1280, "payAmount": 24320 },
      { "merchantId": 7, "shopName": "山野茶铺",
        "items": [ { "skuId": 301, "name": "明前龙井", "spec": { "规格": "50g" },
                     "price": 8000, "quantity": 1, "subtotal": 8000 } ],
        "goodsAmount": 8000, "shippingFee": 1000, "discount": 400, "payAmount": 8600 } ],
    "summary": { "goodsAmount": 33600, "discount": 1680, "shippingFee": 1000, "payAmount": 32920,
                 "orderType": "NORMAL", "deposit": 0, "balance": 0 },
    "coupons": {
      "usable": [ { "id": 5, "name": "满 300 减 16.8", "value": 1680, "minAmount": 30000 } ],
      "unusable": [ { "id": 6, "name": "满 500 减 50", "reason": "GAP_NOT_REACHED" } ] } } }
```

**金额规则**

1. 每个商家单独算运费：满 `freeThresholdCent` 免，否则 `feeCent`
2. 优惠券只对商品金额生效，按子单商品金额比例分摊，尾差归金额最大的子单
3. `payAmount = goodsAmount - discount + shippingFee`，任何子单不得为负
4. 库存不足直接返回 `40002`，不返回部分结果
5. 整单商品都是预售/定制时，`orderType` 为 `PREORDER` 或 `CUSTOM`：
   `deposit = Σ round(行金额 × 定金比例)`（最低 1 元、不超过应付），`balance = payAmount - deposit`
6. 现货与预售/定制混在一张单里返回 `40001`「预售/定制商品请与现货分开下单」

## POST /orders

**权限**：登录 · **幂等**：`Idempotency-Key` 必填

**请求头**

```http
Idempotency-Key: 7d1b0c9e-2f4a-4b8c-9d10-6e5f4a3b2c1d
```

**请求**：与预览相同的 `addressId`、`couponId`、`items`，外加 `remark`（可选，最长 200）与 `flawAck`（商品要求确认手工痕迹时必须为 `true`，否则 `10001`）。`items[].options` 传定制项 `[{ "optionId": 9, "value": "小明" }]`，服务端校验必填/字数/单选值并计入行小计

**响应 201**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": {
    "orderNo": "KD202610270001",
    "status": "PENDING_PAYMENT",
    "payAmount": 32920,
    "expireAt": "2026-10-27T14:20:00+08:00",
    "paymentNo": "PAY202610270001",
    "payUrl": "/mock-pay/PAY202610270001",
    "subOrders": [
      { "subOrderNo": "KD202610270001-3", "shopName": "山野杂货", "payAmount": 24320 },
      { "subOrderNo": "KD202610270001-7", "shopName": "山野茶铺", "payAmount": 8600 } ] } }
```

**事务内做的事**：校验库存 → 逐 SKU 锁定 → 生成主单与子单 → 占用优惠券 → 写 outbox（下单邮件）→ 返回支付单号。

**错误**：`40002` 库存不足 · `40003` 购物车为空 · `40006` 重复提交 · `40011` 优惠券不可用 · `40014` 地址无效 · `40001` 现货与预售/定制混单

> 同一 `Idempotency-Key` 重复请求，返回首次的响应体，不新建订单。
> 响应里的 `payAmount` 是**本次应付**：预售/定制订单为定金；`expireAt` 分别为 24 小时 / 15 分钟。

# 五、支付

## POST /payments

**权限**：登录 · **幂等**：`Idempotency-Key`

**请求**

```json
{ "orderNo": "KD202610270001" }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "paymentNo": "PAY202610270001", "amount": 32920,
            "purpose": "FULL", "status": "PENDING",
            "payUrl": "/mock-pay/PAY202610270001",
            "expireAt": "2026-10-27T14:20:00+08:00" } }
```

`purpose`：`FULL` 一次付清 / `DEPOSIT` 定金 / `BALANCE` 尾款。
预售/定制订单在待付款阶段只创建定金支付单（金额 `deposit`，24 小时有效）；制作中阶段创建尾款支付单（金额 `balance`，截止时间取 `balanceDueAt`）。

同一订单重复创建支付：同用途、未过期的直接复用，已过期的关闭旧的再建新的。

# 八、售后

售后单是子单完成后的独立流程：仅退款 / 退货退款，商家审核，平台可在超时或纠纷时介入。
退款金额为子单剩余可退金额（整子单），与旧退款共用底层退款执行与结算口径。

## POST /orders/{orderNo}/sub-orders/{subOrderNo}/after-sales

**权限**：登录 · 仅本人子单 · 子单已完成且未超过 15 天

**请求**

```json
{ "type": "REFUND_ONLY", "reasonCode": "QUALITY",
  "description": "杯口有缺口", "evidence": ["after-sales/abc.jpg"] }
```

| 字段 | 规则 |
|---|---|
| type | `REFUND_ONLY` 仅退款 / `RETURN_REFUND` 退货退款 |
| reasonCode | `QUALITY` / `NOT_AS_DESCRIBED` / `DAMAGED` / `WRONG_ITEM` / `NO_LONGER_NEEDED` / `OTHER`；定制订单仅前两项 |
| evidence | 最多 3 张，先调 `POST /uploads/image` 拿 key |

**响应 201**：返回售后单（`status=APPLIED`，`refundAmount` 为可退金额）

**错误**：`40026` 不满足申请条件 · `40027` 已有售后单

## GET /me/after-sales

**权限**：登录 · 返回本人售后单（倒序，最多 100 条）

## GET /me/after-sales/{asNo}

**权限**：本人 · 返回详情与 `logs` 时间线

## POST /me/after-sales/{asNo}/reapply

**权限**：本人 · 仅 `REJECTED` 且 `reapplyCount < 1`

**请求**：同申请 · **响应 200**：售后单回到 `APPLIED`，`reapplyCount + 1`

**错误**：`40025` 状态不允许 / 补充机会已用完

## POST /me/after-sales/{asNo}/return

**权限**：本人 · 仅 `RETURNING` 且尚未填写过物流

**请求**

```json
{ "carrier": "顺丰速运", "trackingNo": "SF1234567890" }
```

**响应 200**：售后单带上 `returnCarrier`、`returnTrackingNo`、`returnShippedAt`。

**规则**：商家同意退货退款后 7 天内必须填写寄回物流，逾期售后自动关闭（`CLOSED`）。

**错误**：`40025` 状态不允许 / 已填写过

> 商家 48 小时未审核：仅退款由系统自动通过并退款；退货退款转平台介入（`ESCALATED`），进度可在售后详情查看。
