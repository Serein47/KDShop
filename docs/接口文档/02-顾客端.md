## GET /products

**权限**：公开

**查询参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| keyword | string | 匹配名称与副标题，最长 50 |
| categoryId | long | 传一级类目时自动包含其子类目 |
| minPrice / maxPrice | int | 单位分，闭区间 |
| sort | string | `sales_desc` / `price_asc` / `price_desc` / `created_desc`，默认 `created_desc` |
| page / size | int | 默认 1 / 20 |

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": {
    "items": [

    "total": 37, "page": 1, "size": 20, "hasNext": true } }
```

只返回 `status = ON` 且商家 `ACTIVE` 的商品。

## POST /cart/merge

游客购物车存本地，登录后合并。

**权限**：登录

**请求**

```json
{ "items": [ { "skuId": 101, "quantity": 1 }, { "skuId": 205, "quantity": 2 } ] }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "merged": 2, "dropped": [ { "skuId": 205, "reason": "STOCK_INSUFFICIENT", "available": 0 } ] } }
```

冲突策略：同 SKU 数量相加，超过库存按可买上限截断；下架商品丢弃并返回原因。

# 三、结算与下单

## POST /checkout/preview

结算前预览：算钱、拆单、算券，**不落库、不锁库存**。

**权限**：登录

**请求**

```json
{ "addressId": 12, "couponId": 5,
  "items": [ { "skuId": 101, "quantity": 2 }, { "skuId": 301, "quantity": 1 } ] }
```

| 字段 | 必填 | 说明 |
|---|---|---|
| addressId | 否 | 不传则用默认地址；影响运费（首版运费与地址无关，保留字段） |
| couponId | 否 | 传了但不可用时返回 40011 |
| items | 是 | 传 `cartItemIds` 或 `skuId+quantity` 二选一 |

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": {
    "subOrders": [
      { "merchantId": 3, "shopName": "山野杂货",
        "items": [ { "skuId": 101, "name": "手冲咖啡套装", "spec": { "颜色": "白色" },
                     "price": 12800, "quantity": 2, "subtotal": 25600 } ],
        "goodsAmount": 25600, "shippingFee": 0, "discount": 1280, "payAmount": 24320 },
      { "merchantId": 7, "shopName": "山野茶铺",
        "items": [ { "skuId": 301, "name": "明前龙井", "spec": { "规格": "50g" },
                     "price": 8000, "quantity": 1, "subtotal": 8000 } ],
        "goodsAmount": 8000, "shippingFee": 1000, "discount": 400, "payAmount": 8600 } ],
    "summary": { "goodsAmount": 33600, "discount": 1680, "shippingFee": 1000, "payAmount": 32920 },
    "coupons": {
      "usable": [ { "id": 5, "name": "满 300 减 16.8", "value": 1680, "minAmount": 30000 } ],
      "unusable": [ { "id": 6, "name": "满 500 减 50", "reason": "GAP_NOT_REACHED" } ] } } }
```

**金额规则**

1. 每个商家单独算运费：满 `freeThresholdCent` 免，否则 `feeCent`
2. 优惠券只对商品金额生效，按子单商品金额比例分摊，尾差归金额最大的子单
3. `payAmount = goodsAmount - discount + shippingFee`，任何子单不得为负
4. 库存不足直接返回 `40002`，不返回部分结果

## POST /orders

**权限**：登录 · **幂等**：`Idempotency-Key` 必填

**请求头**

```http
Idempotency-Key: 7d1b0c9e-2f4a-4b8c-9d10-6e5f4a3b2c1d
```

**请求**：与预览相同的 `addressId`、`couponId`、`items`，外加 `remark`（可选，最长 200）

**响应 201**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": {
    "orderNo": "KD202610270001",
    "status": "PENDING_PAYMENT",
    "payAmount": 32920,
    "expireAt": "2026-10-27T14:20:00+08:00",
    "paymentNo": "PAY202610270001",
    "payUrl": "/mock-pay/PAY202610270001",
    "subOrders": [
      { "subOrderNo": "KD202610270001-3", "shopName": "山野杂货", "payAmount": 24320 },
      { "subOrderNo": "KD202610270001-7", "shopName": "山野茶铺", "payAmount": 8600 } ] } }
```

**事务内做的事**：校验库存 → 逐 SKU 锁定 → 生成主单与子单 → 占用优惠券 → 写 outbox（下单邮件）→ 返回支付单号。

**错误**：`40002` 库存不足 · `40003` 购物车为空 · `40006` 重复提交 · `40011` 优惠券不可用 · `40014` 地址无效

> 同一 `Idempotency-Key` 重复请求，返回首次的响应体，不新建订单。

## POST /orders/{orderNo}/cancel

**权限**：登录 · 仅本人、仅 `PENDING_PAYMENT`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "orderNo": "KD202610270001", "status": "CANCELLED" } }
```

**错误**：`40005` 当前状态不可取消

副作用：释放全部锁定库存、优惠券退回、子单转已取消。

---

## POST /orders/{orderNo}/sub-orders/{subOrderNo}/confirm

**权限**：登录 · 仅本人、仅 `SHIPPED`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "subOrderNo": "KD202610270001-3", "status": "COMPLETED",
            "orderStatus": "PARTIALLY_SHIPPED" } }
```

返回主单最新状态，前端不用再拉一次。重复确认幂等。

---

## POST /orders/{orderNo}/sub-orders/{subOrderNo}/refunds

**权限**：登录 · 仅本人、`PENDING_SHIPMENT` 或 `SHIPPED`

**请求**

```json
{ "reason": "不想要了" }
```

**响应 201**

```json

            "amount": 24320, "status": "APPLIED" } }
```

# 七、评价

## POST /reviews

**权限**：登录 · 订单完成后、每个订单项一次

**请求**

```json
{ "orderItemId": 5501, "rating": 5, "content": "豆子很新鲜，滤杯做工好" }
```

| 字段 | 规则 |
|---|---|
| orderItemId | 必须属于当前用户、且对应子单已 `COMPLETED` |
| rating | 1–5 整数 |
| content | 10–500 字，禁止纯表情 |

**响应 201**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "reviewId": 501, "status": "VISIBLE" } }
```

**错误**：`40013` 该订单项已评价 · `40005` 订单未完成
