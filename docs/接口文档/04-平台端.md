# 04 平台端

平台后台接口，全部挂在 `/admin` 下。客服只能调用带「客服」标记的接口，其余需要运营或管理员。

---

# 一、商家管理

## GET /admin/merchants

**权限**：运营 · 参数 `status`(PENDING/ACTIVE/REJECTED/SUSPENDED)、`keyword`、`page`、`size`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [ { "id": 3, "shopName": "山野杂货", "status": "PENDING",
                         "contactName": "李四", "contactPhone": "139****1111",
                         "appliedAt": "2026-10-27T14:30:00+08:00" } ],
            "total": 1, "page": 1, "size": 20, "hasNext": false } }
```

## GET /admin/merchants/{id}

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "id": 3, "shopName": "山野杂货", "status": "PENDING",
            "contactName": "李四", "contactPhone": "13900001111",
            "licenseImage": "https://.../m/license/1.jpg",
            "productCount": 0, "gmv": 0, "commissionRate": 500,
            "reviews": [ { "result": "REJECTED", "reason": "执照模糊",
                           "reviewer": "运营小王", "at": "2026-10-20T10:00:00+08:00" } ] } }
```

## POST /admin/merchants/{id}/approve

**权限**：运营 · 仅 `PENDING`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "id": 3, "status": "ACTIVE", "rolesGranted": ["MERCHANT"] } }
```

副作用：店铺激活、给店主加 `MERCHANT` 角色、写 outbox（入驻通过邮件）、写审计。

## POST /admin/merchants/{id}/reject

**请求**：`{ "reason": "营业执照图片不清晰" }` · **响应 200**：`{ "status": "REJECTED" }`

## POST /admin/merchants/{id}/suspend

**请求**：`{ "reason": "售假投诉成立" }`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "id": 3, "status": "SUSPENDED", "offlinedProducts": 18 } }
```

封禁副作用：商品全部强制下架、商家不能登录；**已付款未发货的子单仍可发货**。

## POST /admin/merchants/{id}/resume

**响应 200**：`{ "status": "ACTIVE" }`，商品不自动恢复上架，由商家自行开启。

## PUT /admin/merchants/{id}/commission

**权限**：管理员

**请求**：`{ "commissionRate": 800 }`（基点，800 = 8%）

**响应 200**：`{ "id": 3, "commissionRate": 800, "effectiveFrom": "下一张结算单" }`

# 二、订单与退款

## GET /admin/orders

**权限**：客服 · 参数 `status`、`orderNo`、`keyword`(收货人手机号)、`from`、`to`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [ { "orderNo": "KD202610270001", "status": "PAID",
                         "userNickname": "张**", "payAmount": 32920,
                         "subOrderCount": 2, "createdAt": "2026-10-27T14:05:00+08:00" } ],
            "total": 1, "page": 1, "size": 20, "hasNext": false } }
```

## GET /admin/orders/{orderNo}

返回主单详情 + 子单列表（结构同顾客端订单详情，额外含 `payment` 与 `merchantId`）。

## GET /admin/refunds

**权限**：客服 · 参数 `status`、`keyword`

## POST /admin/refunds/{refundNo}/approve

**权限**：客服 · 强制同意（纠纷介入）

**请求**：`{ "reason": "商家超时未处理，平台介入" }`

**响应 200**：`{ "status": "REFUNDED", "subOrderStatus": "REFUNDED" }`

## POST /admin/refunds/{refundNo}/reject

**请求**：`{ "reason": "证据不足" }` · **响应 200**：`{ "status": "REJECTED" }`

# 三、顾客管理

## GET /admin/customers

**权限**：客服（只读）· 参数 `keyword`(邮箱/昵称/手机)、`status`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [ { "id": 1001, "nickname": "张**", "email": "z***@example.com",
                         "phone": "138****8000", "status": "ACTIVE",
                         "orderCount": 6, "totalSpent": 128000,
                         "createdAt": "2026-09-01T10:00:00+08:00" } ],
            "total": 1, "page": 1, "size": 20, "hasNext": false } }
```

## POST /admin/customers/{id}/disable

**权限**：运营 · **响应 200**：`{ "id": 1001, "status": "DISABLED", "sessionsRevoked": 2 }`

禁用即时踢下线；已有订单不受影响。

## POST /admin/customers/{id}/enable

**响应 200**：`{ "status": "ACTIVE" }`

# 四、商品与类目

## GET /admin/products

**权限**：运营 · 参数 `keyword`、`merchantId`、`status`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [ { "id": 88, "name": "手冲咖啡套装", "shopName": "山野杂货",
                         "merchantId": 3, "status": "ON", "minPrice": 12800,
                         "totalStock": 15, "salesCount": 42 } ],
            "total": 1, "page": 1, "size": 20, "hasNext": false } }
```

## PUT /admin/products/{id}/force-offline

**权限**：运营

**请求**：`{ "reason": "涉嫌虚假宣传" }`

**响应 200**：`{ "id": 88, "status": "OFF", "offlineReason": "涉嫌虚假宣传" }`

## GET /admin/categories

返回类目树（同顾客端结构，含 `productCount`）。

## POST /admin/categories

**请求**：`{ "name": "咖啡", "parentId": 1, "sort": 1 }`
**响应 201**：`{ "id": 11 }`
**规则**：两级封顶；同名同级唯一。

## PUT /admin/categories/{id}

**请求**：`{ "name": "咖啡豆", "sort": 3, "status": "ON" }`

## DELETE /admin/categories/{id}

有商品或有子类目时返回 `409`。

```json
            "total": 1, "page": 1, "size": 20, "hasNext": false } }
```

## POST /admin/coupons

**请求**

```json
{ "code": "AUTUMN300", "name": "满 300 减 16.8", "type": "THRESHOLD",
  "value": 1680, "minAmount": 30000, "total": 1000,
```

# 六、结算

## POST /admin/settlements/generate

**权限**：运营

**请求**

```json
{ "periodStart": "2026-10-13", "periodEnd": "2026-10-19" }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "generated": [ { "merchantId": 3, "settlementNo": "ST20261020003",
                             "grossAmount": 486000, "commission": 24300, "netAmount": 461700 } ],
            "skipped": [ { "merchantId": 7, "reason": "NO_ELIGIBLE_ORDER" } ] } }
```

**规则**：只结算「已完成 + 过售后期 + 未被结算过」的子单；同一商家同一周期重复生成返回 `40020`。

## GET /admin/settlements

**参数**：`merchantId`、`status`、`period`

## POST /admin/settlements/{settlementNo}/settle

**权限**：运营 · 模拟打款

**响应 200**：`{ "settlementNo": "ST20261020003", "status": "SETTLED", "settledAt": "..." }`

# 七、看板、审计与权限

**权限**：客服只读 / 运营

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "today": { "gmv": 1280000, "orderCount": 96, "merchantCount": 12,
                       "commission": 64000, "newCustomers": 8 },
            "last7Days": [ { "date": "2026-10-21", "gmv": 980000, "orderCount": 72 } ],
            "topProducts": [ { "productId": 88, "name": "手冲咖啡套装", "salesCount": 42 } ],
            "pending": { "merchantApplications": 2, "refunds": 5 } } }
```

## GET /admin/audit-logs

**权限**：管理员 · 参数 `actorId`、`action`、`targetType`、`from`、`to`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [ { "id": 9001, "actorName": "运营小王", "actorType": "ADMIN",
                         "action": "PRODUCT_FORCE_OFFLINE", "targetType": "PRODUCT",
                         "targetId": "88", "before": { "status": "ON" },
                         "after": { "status": "OFF" }, "ip": "10.0.0.8",
                         "at": "2026-10-27T15:00:00+08:00" } ],
            "total": 1, "page": 1, "size": 20, "hasNext": false } }
```

## POST /admin/users/{id}/roles

**权限**：管理员

**请求**

```json
{ "roles": ["CUSTOMER", "OPERATOR"] }
```

**响应 200**：`{ "userId": 1001, "roles": ["CUSTOMER", "OPERATOR"], "effectiveNow": true }`

**规则**：全量替换语义；不能移除自己的 `ADMIN`；变更写审计并立即生效。
