# ADR-0001 技术栈与部署基线

- 状态：已接受
- 日期：2026-10-27

## 背景

7 天内交付一个可演示、可评审的电商站，包含顾客端、运营端、模拟支付与邮件通知。

## 决策

| 层 | 选型 | 理由 |
|---|---|---|
| 后端 | Spring Boot 3 + MyBatis-Plus + MySQL 8 + Redis | 生态成熟，团队熟悉；MyBatis-Plus 减少样板代码 |
| 前端 | Vue 3 + TS + Vite + Element Plus + Pinia | 中后台组件齐全，上手快 |
| 存储 | Docker Compose 起 MySQL/Redis/MinIO/Mailpit | 一条命令起步，环境可复制 |
| 通信 | REST + JSON，统一响应体与错误码 | 契约清晰，便于前端 mock 与测试 |
| 部署 | 阿里云 + Docker Compose + Caddy | 用户自行部署，方案简单可复现 |

## 后果

- 单仓多模块（backend / frontend / infra / docs），CI 按路径过滤
- 不引入 ES、消息队列：100 SKU 与演示流量用不上
- V2 的 Python agent 作为独立服务接入，不改变主站技术栈

## 何时重审

商品量超过 1 万、需要多实例水平扩展、或接入真实支付通道时。
