# ADR-0004 退款与库存回补

- 状态：已接受
- 日期：2026-10-27

## 背景

模拟支付支持整单退款。退款成功后，这笔库存该不该加回来，取决于货有没有出去。

## 决策

| 退款时订单状态 | 库存处理 | 理由 |
|---|---|---|
| 已付款（未发货） | 回补 `stock += n`，写 `stock_logs` | 货没出库，库存确实回来了 |
| 已发货 | 不回补 | 货已在途，回补会凭空多出可售库存 |

优惠券：退款成功后返还为 `UNUSED`，但已过期的券返还后仍为 `EXPIRED`。

## 后果

- 退款流程要读订单状态分支，不能无条件加库存
- 已发货退款会产生「账面库存 < 实际可售」的差异，由人工盘点修正，这是行业常态
- 看板「退货率」按退款单统计，不按库存变动统计

## 何时重审

支持部分退款或换货时，需要按订单行粒度重做。
