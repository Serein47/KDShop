# 03 商家端

商家后台接口。所有 `/merchant/*` 接口的 `merchantId` 由服务端从会话解析，**不接受前端传入**；越权一律 `30003`。

---

# 一、入驻

## POST /merchant/applications

**权限**：登录（顾客）

**请求**

```json
{ "shopName": "山野杂货", "contactName": "李四", "contactPhone": "13900001111",
  "description": "只卖当季山货", "licenseImage": "https://.../m/license/1.jpg" }
```

| 字段 | 必填 | 规则 |
|---|---|---|
| shopName | 是 | 2–30 字，全平台唯一 |
| contactName | 是 | 2–20 字 |
| contactPhone | 是 | 11 位手机号 |
| description | 否 | 最长 200 字 |
| licenseImage | 是 | 先调 `POST /files` 上传，传返回的 URL |

**响应 201**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "merchantId": 3, "status": "PENDING", "submittedAt": "2026-10-27T14:30:00+08:00" } }
```

**错误**：`40018` 已有一条待审核申请 · `40015` 店铺名已被占用

## GET /merchant/applications/me

**权限**：登录

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "merchantId": 3, "shopName": "山野杂货", "status": "REJECTED",
            "rejectReason": "营业执照图片不清晰，请重新上传",
            "submittedAt": "2026-10-20T09:00:00+08:00",
            "reviewedAt": "2026-10-21T10:30:00+08:00" } }
```

从未申请过返回 `data: null`。

## PUT /merchant/applications/me

**权限**：登录 · 仅 `REJECTED` 可改

**请求**：同 `POST`，**响应 200**：`{ "status": "PENDING" }`

# 二、店铺

## GET /merchant/profile

**权限**：商家

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "id": 3, "shopName": "山野杂货", "logo": "https://.../m/3/logo.png",
            "description": "只卖当季山货", "commissionRate": 500,
            "status": "ACTIVE", "createdAt": "2026-08-01T10:00:00+08:00" } }
```

`commissionRate = 500` 表示 5%（基点）。

## PUT /merchant/profile

**请求**：`{ "logo": "...", "description": "...", "contactPhone": "..." }`
**响应 200**：返回更新后的店铺对象。店名不可改，需联系平台。

## GET /merchant/dashboard

**权限**：商家

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "today": { "salesAmount": 128000, "orderCount": 9, "pendingShipment": 3 },
            "last7Days": [ { "date": "2026-10-21", "salesAmount": 98000, "orderCount": 7 } ],
            "topProducts": [ { "productId": 88, "name": "手冲咖啡套装", "salesCount": 42 } ] } }
```

# 三、商品

## GET /merchant/products

**权限**：商家 · 查询参数 `keyword`、`status`(ON/OFF)、`page`、`size`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [ { "id": 88, "name": "手冲咖啡套装", "status": "ON",
                         "minPrice": 12800, "totalStock": 15, "salesCount": 42,
                         "updatedAt": "2026-10-25T11:00:00+08:00" } ],
            "total": 18, "page": 1, "size": 20, "hasNext": false } }
```

## POST /merchant/products

**权限**：商家

**请求**

```json
{ "name": "手冲咖啡套装", "subtitle": "入门一次到位", "categoryId": 11,
  "description": "<p>含滤杯、滤纸与 200g 豆子</p>",
  "images": ["https://.../p/88/1.jpg", "https://.../p/88/2.jpg"],
  "status": "ON",
  "skus": [
    { "spec": { "颜色": "白色" }, "price": 12800, "originalPrice": 15800, "stock": 12 },
    { "spec": { "颜色": "黑色" }, "price": 16800, "originalPrice": 19800, "stock": 3 } ] }
```

**响应 201**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "id": 88, "skus": [ { "id": 101, "spec": { "颜色": "白色" } } ] } }
```

**规则**：至少 1 个 SKU；`spec` 取值组合在同一商品内唯一；价格 ≤ 原价；库存 ≥ 0。

## PUT /merchant/products/{id}

**请求**：同 `POST`，SKU 数组带 `id` 表示更新、不带表示新增、缺失的旧 SKU 视为删除（已售出的 SKU 不允许删，只能下架）。

**响应 200**：`{ "id": 88 }`

## PUT /merchant/products/{id}/status

**请求**：`{ "status": "OFF" }` · **响应 200**：`{ "id": 88, "status": "OFF" }`

下架后立即从前台消失；在途订单不受影响。

## DELETE /merchant/products/{id}

**软删**，有未完成子单时返回 `409`。

# 四、订单与发货

## GET /merchant/orders

**权限**：商家 · 参数 `status`、`keyword`(子单号/收货人)、`from`、`to`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [
      { "subOrderNo": "KD202610270001-3", "status": "PENDING_SHIPMENT",
        "payAmount": 24320, "itemCount": 2,
        "receiver": "张**", "createdAt": "2026-10-27T14:05:00+08:00",
        "shipDeadline": "2026-10-29T14:05:00+08:00" } ],
    "total": 12, "page": 1, "size": 20, "hasNext": true } }
```

## GET /merchant/orders/{subOrderNo}

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "subOrderNo": "KD202610270001-3", "orderNo": "KD202610270001",
            "status": "SHIPPED", "payAmount": 24320,
            "address": { "receiver": "张三", "phone": "138****8000",
                         "detail": "浙江省杭州市西湖区文三路 1 号" },
            "items": [ { "name": "手冲咖啡套装", "spec": { "颜色": "白色" },
                         "price": 12800, "quantity": 2, "subtotal": 25600 } ],
            "shipment": { "carrier": "顺丰", "trackingNo": "SF1234567890",
                          "shippedAt": "2026-10-27T16:00:00+08:00" },
            "timeline": [ { "status": "SHIPPED", "at": "2026-10-27T16:00:00+08:00" } ] } }
```

## POST /merchant/orders/{subOrderNo}/ship

**权限**：商家 · 仅 `PENDING_SHIPMENT`

**请求**

```json
{ "carrier": "顺丰", "trackingNo": "SF1234567890" }
```

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "subOrderNo": "KD202610270001-3", "status": "SHIPPED",
            "orderStatus": "PARTIALLY_SHIPPED" } }
```

**错误**：`40019` 子单状态不允许 · 重复发货返回 `409`
副作用：写 `shipments`、子单转已发货、重算主单、写 outbox（发货邮件）。

# 五、退款

## GET /merchant/refunds

**参数**：`status`、`page`、`size`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "items": [ { "refundNo": "RF202610270001", "subOrderNo": "KD202610270001-3",
                         "amount": 24320, "reason": "不想要了", "status": "APPLIED",
                         "appliedAt": "2026-10-28T09:00:00+08:00" } ],
            "total": 1, "page": 1, "size": 20, "hasNext": false } }
```

## POST /merchant/refunds/{refundNo}/approve

**权限**：商家 · 仅本店 `APPLIED`

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "refundNo": "RF202610270001", "status": "REFUNDED",
            "subOrderStatus": "REFUNDED", "orderStatus": "PARTIALLY_SHIPPED" } }
```

副作用：调模拟网关退款 → 库存按 ADR-0004 处理 → 子单转已退款 → 重算主单 → 写 outbox。

## POST /merchant/refunds/{refundNo}/reject

**请求**：`{ "reason": "商品已拆封，不支持无理由退货" }`

**响应 200**：`{ "status": "REJECTED" }`
**错误**：`40010` 状态不允许 · 驳回原因必填

# 七、文件上传

## POST /files

**权限**：登录 · `multipart/form-data`

**请求**：`file`（jpg/png/webp，≤ 5MB）、`scene`（`product` / `merchant-license` / `avatar`）

**响应 200**

```json
{ "code": 0, "message": "ok", "traceId": "a1b2c3",
  "data": { "url": "https://.../product/88/20261027-abc.jpg", "size": 348221,
            "contentType": "image/jpeg" } }
```

**错误**：`10001` 类型或大小不合规。服务端会二次校验 MIME 与文件头，不信任扩展名。
