# M2 交易主线

目标：跑通「逛 → 加购 → 下单 → 支付 → 发货 → 收货」这条主链路。这是项目的骨架，其余功能都挂在它上面。

---

## ISSUE-06 认证与会话

- 里程碑：M2 交易主线
- 标签：`backend`, `auth`, `p0`
- 依赖：#03, #04
- 需求：REQ-C-01/03/04、ADR-0006

**背景**：注册、登录、登出、会话与 CSRF。

**验收线**
- [ ] 注册后能登录，`GET /auth/me` 返回角色
- [ ] 非 GET 请求缺 `X-XSRF-TOKEN` 返回 403
- [ ] 登录后 session id 轮换；登出后旧 Cookie 失效
- [ ] 连续 5 次密码错误锁定 15 分钟（`20004`）

**涉及**：`POST /auth/register`、`POST /auth/login`、`GET /auth/csrf`

## ISSUE-07 邮箱验证与密码重置

- 里程碑：M2 交易主线
- 标签：`backend`, `auth`
- 依赖：#06, #16
- 需求：REQ-C-02/05

**背景**：验证与重置都靠一次性令牌，令牌只存哈希。

**验收线**
- [ ] 验证邮件进 outbox，Mailpit 可见，点链接完成验证
- [ ] 令牌一次性、30 分钟过期，重复使用返回 `20007`
- [ ] 重置成功后该用户全部会话失效
- [ ] 未验证邮箱登录返回 `20005`

**涉及**：`auth_tokens`、`POST /auth/verify-email`

## ISSUE-09 购物车

- 里程碑：M2 交易主线
- 标签：`backend`, `frontend`, `cart`
- 依赖：#08
- 需求：REQ-C-20/21/22

**背景**：加购、改量、删除、游客合并。

**验收线**
- [ ] 同 SKU 重复加购累加数量，超库存返回 `40002`
- [ ] 游客本地购物车登录后合并，冲突按可买上限截断并返回丢弃原因
- [ ] 数量改 0 视为删除
- [ ] 并发改同一行不出现负数或超库存

**涉及**：`cart_items`、`POST /cart/items`、`POST /cart/merge`

## ISSUE-10 结算预览

- 里程碑：M2 交易主线
- 标签：`backend`, `order`, `p0`
- 依赖：#09
- 需求：REQ-C-22、REQ-C-31、ADR-0005

**背景**：算钱、按商家拆单、算券，不落库。

**验收线**
- [ ] 跨商家购物车返回多个 `subOrders`，金额之和等于汇总
- [ ] 运费按子单独立计算（满 99 免运费，否则 10 元）
- [ ] 优惠券按商品金额比例分摊，尾差归金额最大的子单
- [ ] 库存不足直接 `40002`，不返回部分结果

**涉及**：`POST /checkout/preview`、`ShippingCalculator`、`DiscountAllocator`

## ISSUE-11 下单与拆单落库

- 里程碑：M2 交易主线
- 标签：`backend`, `order`, `p0`
- 依赖：#10
- 需求：REQ-C-31/32、ADR-0005

**背景**：事务内建主单与子单、锁库存、占券，支持幂等。

**验收线**
- [ ] 生成 1 主单 + N 子单，子单号形如 `KD...-3`
- [ ] Σ子单应付 = 主单应付
- [ ] 任一 SKU 库存不足 → 整单失败且已锁库存全部回滚
- [ ] 同一 `Idempotency-Key` 重复提交返回同一订单

**涉及**：`POST /orders`、`orders`/`merchant_orders`/`order_items`

- 依赖：#11
- 需求：REQ-C-33、ADR-0007

- 需求：REQ-C-34、`order-lifecycle.md`

**背景**：回调通过后的入账事务。

**验收线**

## ISSUE-15 定时任务

- 依赖：#14
- 需求：REQ-C-32、`order-lifecycle.md`

**背景**：超时取消、自动确认收货。

**验收线**
- [ ] 15 分钟未支付自动取消并释放库存，重复扫描无副作用

## ISSUE-16 邮件 outbox

- 里程碑：M2 交易主线
- 标签：`backend`, `infra`
- 依赖：#04
- 需求：REQ-C-60/61、`email-templates.md`

**背景**：邮件不真发，写库 + 异步投递 + Mailpit 展示。

**验收线**
- [ ] 5 类模板可渲染出 HTML 与纯文本
- [ ] 业务键唯一，重复事件只入队一次
- [ ] 投递失败重试 3 次后标 FAILED，不影响主流程
- [ ] 生产配置下使用 OutboxOnlySender，不触达真实邮箱

**涉及**：`email_outbox`、`MailSender`、`mail-templates/`
