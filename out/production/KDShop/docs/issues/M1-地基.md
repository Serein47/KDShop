# M1 地基

目标：克隆下来能编译、能起服务、CI 能跑绿。这一层不写业务。

---

## ISSUE-01 仓库骨架与本地构建

- 里程碑：M1 地基
- 标签：`backend`, `frontend`, `infra`
- 依赖：无
- 需求：REQ-N-01

**背景**：建立 `backend/`、`frontend/`、`infra/`、`docs/` 四段结构，跑通最小构建。

**验收线**
- [ ] `mvn -q -DskipTests package` 产出可执行 jar
- [ ] `npm ci && npm run build` 产出 `dist/`
- [ ] `.env.example` 列出全部变量并注明用途
- [ ] `README.md` 有「快速开始」与「目录结构」两节

**涉及**：`backend/pom.xml`、`frontend/package.json`、根 `README.md`、`.env.example`

## ISSUE-02 基础设施编排

- 里程碑：M1 地基
- 标签：`infra`
- 依赖：#01
- 需求：REQ-N-01

**背景**：本地一键起 MySQL、Redis、MinIO、Mailpit。

**涉及**：`infra/docker-compose.yml`、`infra/.env.example`

## ISSUE-03 数据库迁移与种子数据

## ISSUE-04 统一响应、错误码与异常

- 里程碑：M1 地基
- 标签：`backend`, `common`
- 依赖：#01
- 需求：REQ-N-05、`docs/error-codes.md`

**背景**：所有接口返回同一结构，错误码集中管理。

**验收线**
- [ ] 成功返回 `{code:0, message:"ok", data, traceId}`
- [ ] 参数校验失败返回 `10001` 且 `data` 带字段级错误
- [ ] 未捕获异常返回 `50001`，不泄露堆栈与 SQL
- [ ] 每个响应都带 `traceId`，日志里能按它串起一次请求

**涉及**：`common/response`、`common/exception`、`TraceIdFilter`

## ISSUE-05 CI 流水线

- 里程碑：M1 地基
- 标签：`ci`
- 依赖：#01

**背景**：每次 push 与 PR 自动跑检查，红了不许合并。

**验收线**
- [ ] PR 触发后端编译 + 单测、前端 lint + build
- [ ] 缓存 Maven 与 npm 依赖，单次流水线 5 分钟内
- [ ] 失败时在 PR 页面显示具体哪一步红
- [ ] main 分支开启「必须 CI 通过才能合并」

**涉及**：`.github/workflows/ci.yml`
