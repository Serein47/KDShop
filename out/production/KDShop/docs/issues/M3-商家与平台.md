# M3 商家与平台

目标：让「商家能卖、平台能管」，并打通结算闭环。

---

## ISSUE-17 商家入驻申请与审核

- 里程碑：M3 商家与平台
- 标签：`backend`, `merchant`, `p0`
- 依赖：#06, #16
- 需求：REQ-C-70/71/72、REQ-A-60

**背景**：顾客提交入驻 → 运营审核 → 通过后获得商家身份。

**验收线**
- [ ] 提交申请落 `PENDING`，重复提交返回 `40018`
- [ ] 审核通过：商家转 `ACTIVE`、授予 `MERCHANT` 角色、发通知邮件
- [ ] 驳回填原因，用户可改后重提回到 `PENDING`
- [ ] 审核动作写审计日志

**涉及**：`merchants`、`POST /merchant/applications`、`POST /admin/merchants/{id}/approve`

## ISSUE-19 商家商品管理与图片上传

- 里程碑：M3 商家与平台
- 标签：`backend`, `frontend`, `merchant`, `catalog`
- 依赖：#08, #17
- 需求：REQ-M-03/04

**背景**：商家维护自己的商品与库存，图片进 MinIO。

**验收线**
- [ ] 新建/编辑商品含多 SKU，`spec` 组合唯一，价格 ≤ 原价
- [ ] 上下架即时影响前台可见性
- [ ] 库存调整写 `stock_logs`（操作人、前后值、原因）
- [ ] 删除只允许软删，有未完成子单时返回 `409`
- [ ] 图片上传校验 MIME 与文件头，超 5MB 拒绝

**涉及**：`/merchant/products/*`、`POST /files`、`MinIO`

## ISSUE-20 商家子单与发货

- 里程碑：M3 商家与平台
- 标签：`backend`, `frontend`, `merchant`
- 依赖：#19, #14
- 需求：REQ-M-05/06

**背景**：商家只看到含本店商品的子单，发货后重算主单。

**验收线**
- [ ] 列表与详情均按 `merchant_id` 过滤，越权 `30003`
- [ ] 发货写 `shipments`、子单转已发货、发邮件、重算主单
- [ ] 重复发货返回 `409`
- [ ] 被封禁商家的待发货子单仍可发货

**涉及**：`GET /merchant/orders`、`POST /merchant/orders/{no}/ship`

## ISSUE-21 退款申请与商家审核

- 里程碑：M3 商家与平台
- 标签：`backend`, `merchant`, `refund`, `p0`
- 依赖：#20
- 需求：REQ-C-44、REQ-M-07、ADR-0004

**背景**：按子单整单退，商家审，库存按发货状态区别处理。

**验收线**
- [ ] 仅 `PENDING_SHIPMENT`/`SHIPPED` 可申请，重复申请 `409`
- [ ] 同意 → 调网关退款 → 未发货回补库存、已发货不回补
- [ ] 驳回必填原因，子单回到原状态
- [ ] 退款成功后重算主单，全部退完主单转已退款

**涉及**：`refunds`、`POST /merchant/refunds/{no}/approve`

## ISSUE-24 结算生成与对账

- 里程碑：M3 商家与平台
- 标签：`backend`, `settlement`, `p1`
- 依赖：#21, #25
- 需求：REQ-A-62/63、ADR-0005

**背景**：按周期给商家出结算单，防止重复结算与结算后退款。

**验收线**
- [ ] 只结算「已完成 + 过 7 天售后期 + 未被结算」的子单
- [ ] 同商家同周期重复生成返回 `40020`
- [ ] 佣金按基点计算，四舍五入到分；费率改动只影响之后生成的单
- [ ] 每日对账：`Σ settlement_items` 与已完成子单一致，差异告警
- [ ] 商家可查看并导出自己的结算明细 CSV

**涉及**：`settlements`、`settlement_items`、`SettlementJob`

## ISSUE-25 平台看板与审计日志

- 里程碑：M3 商家与平台
- 标签：`backend`, `frontend`, `admin`
- 依赖：#22
- 需求：REQ-A-40/50

**背景**：平台经营数据与操作留痕。

**验收线**
- [ ] 看板：GMV、订单量、商家数、佣金收入、待办（待审商家/待处理退款）
- [ ] 审计覆盖：改价、库存调整、订单状态变更、商家审核、权限变更
- [ ] 审计可按操作人、动作、对象、时间筛选
- [ ] 审计记录只增不改，接口无删除能力

**涉及**：`GET /admin/dashboard`、`GET /admin/audit-logs`、`@Audited`
